# Quantum Ships

**Quantum Ships** is a digital board game inspired by the classic game *Battleships*, enhanced with concepts from quantum physics and probability theory.

Instead of hiding a ship in a single cell, each player defines a **probability distribution** describing where their quantum ship may be located. Using measurements, logic, and deduction, players attempt to reconstruct their opponent’s distribution and launch a precise attack.

The project is fully playable and complete in its current form, with potential extensions planned for the future.

---

## About the Game

Quantum Ships is designed as both a strategic game and an educational tool. It introduces players to probabilistic reasoning and basic ideas inspired by quantum measurement, all within a turn-based competitive setting.

### Game Modes
- **Two-player local turn-based mode**
- **Single-player mode** (planned, work in progress)

### Key Features
- Adjustable grid size and probability resolution  
- Measurement-based information gathering  
- Logical reconstruction of hidden probability distributions  
- Colorblind mode support  
- Clean, minimal UI designed for clarity and reasoning

## Installation & Running the Game

Pre-built versions of the game are available in the **Releases** section of this repository.

### Desktop (Windows & Linux)
1. Download the `.zip` file from **Releases**
2. Extract the archive
3. Run the executable file

No installation is required.

### Web Version
Some releases also include a **WebGL build**, which can be played directly in a web browser.
